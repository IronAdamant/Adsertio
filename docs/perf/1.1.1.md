# Re-measure after the 1.1.1 review fixes

Same harness and machine as [baseline-1.0.0.md](baseline-1.0.0.md) and [1.1.0.md](1.1.0.md). The 1.1.1 edits are checks, hints, and write rules. Nothing in them was kept because it made a read faster.

```sh
cargo test --release --locked --test perf -- --ignored --nocapture
```

Measured on this VM: Linux 6.12.113+ x86_64, Intel(R) Xeon(R) Processor, MemTotal 16387328 kB, rustc 1.83.0 (90b35a623 2024-11-26).

Median, then p95. The 1.1.0 column is the earlier note, not a claim that this run beat it.

| Path | 1.1.0 note | This run |
|---|---|---|
| 100 claims, one 1,000-step Trammel store | 4.1 / 4.3 ms | 4.3 / 4.3 ms |
| Probatio `results/`, 1,000 files | 4.5 / 5.5 ms | 4.3 / 5.5 ms |
| Probatio `results/`, 10,000 files | 50.8 / 54.2 ms | 41.9 / 49.5 ms |

The shared-store view is still about 4 ms. The other rows moved by a few milliseconds, or by about 9 ms on the 10,000-file Probatio run, with three to eleven samples. No ledger code changed, and no Probatio read path changed in 1.1.1, so those gaps are another run on this VM, not a speedup.
